Source code

The game’s source code and change history are available in the GitHub repository.

The source files delivered to your browser can also be read directly: HTML, game logic, Wikipedia queries, categories, word vectors, model runtime, Finnish inflections and Voikko runtime.

Voikko and the Finnish dictionary

Finnish inflections use the Voikko 1.0.1 package, which includes libvoikko 4.3.2 and the Finnish morpho dictionary. The bundle is distributed under GPL-3.0-or-later. Original copyright and alternative licence notices are preserved in the source archive.

Download the corresponding source code and build instructions for Voikko and the dictionary. The dictionary’s authors include Hannu Väisänen, Harri Pitkänen, Teemu Likonen and others named in the source archive.
